# Code of conduct

Prism follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep it about the work. No harassment, insults or personal attacks, in issues, pull requests or anywhere else the project lives.

If someone makes you feel unwelcome, contact the maintainer privately through [GitHub](https://github.com/sjdsjadjajdjsa). Reports are kept confidential.
